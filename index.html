Ringtest

An open benchmark for biomedical peer review

In a ring test, labs analyze the same samples so their results can be compared against a reference. Ringtest uses shared test cases, transparent scoring, and open results to do the same for peer review.

Test protocols, code, and retired test cases will be released under open licenses.

First release planned for early 2027.
